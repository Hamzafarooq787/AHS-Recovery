# AHS Recovery

A Next.js website for AHS Recovery — towing, breakdown assistance, RTC recovery, jump starts, vehicle recovery,
winch-out recovery, accident recovery, motorway breakdown recovery, roadside assistance, 4x4 & off-road recovery,
specialist accident recovery and nationwide vehicle transportation, based in Ilford, Essex.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Structure

- `app/` — Next.js App Router pages (home, services, about, contact, areas)
- `components/` — Reusable UI and page-section components
- `lib/site-config.ts` — Central business details, service list and coverage areas
